# Copper Shop — E-commerce Web Application

A React-based e-commerce project focused on product browsing, shopping workflows, and a responsive user interface.

## Overview

Copper Shop is a web development project created to explore the implementation of an online shopping experience with a React frontend.

## Features

The project README currently documents the following functionality. Please verify each feature against the current implementation before presenting it as complete:

* User authentication
* Product listing, filtering, and sorting
* Shopping cart
* Checkout workflow
* Order history
* Responsive layouts
* Product and order administration

## Technology Stack

* React
* JavaScript
* React Router
* Bootstrap
* React Bootstrap

The repository also includes a `liara.json` deployment configuration.

## Getting Started

### Prerequisites

* Node.js and npm

### Installation

Clone the repository:

```bash
git clone https://github.com/ARS6666/Copper-Shop.git
cd Copper-Shop
npm install
```

Start the development server:

```bash
npm start
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```
